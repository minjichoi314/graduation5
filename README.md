# 나의 MBTI 캐릭터 공방

GitHub Pages 배포용 정적 웹앱입니다. 그림을 포함한 콘텐츠가 `index.html` 안에 들어 있어 별도 빌드나 이미지 폴더 없이 배포할 수 있습니다.

## GitHub Pages 배포

1. ZIP 파일의 압축을 풉니다.
2. 저장소 최상위에 `index.html`과 `README.md`를 올립니다.
3. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
4. 배포 소스를 `Deploy from a branch`로 선택하고, 브랜치와 `/ (root)`를 지정한 뒤 저장합니다.
5. 잠시 후 Pages 설정 화면에 표시되는 주소로 접속합니다.

## 기능

- 16개 상황 문항과 문항별 선택지 삽화
- 1~3단계 탭으로 자유로운 화면 이동
- 결과 유형 안내와 캐릭터 프롬프트 생성
- 프롬프트 복사 및 텍스트 파일 저장
- 모바일 화면 대응
